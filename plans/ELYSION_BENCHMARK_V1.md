# ELYSION benchmark V1

Status: PROPOSED / NON_EXECUTED

Compare base alone, base plus fixed prompt, CÉRÉBRON plus base, SIGMA when bound, ELYSION, ELYSION plus RAG, minimal coalition, agent council, farms/tools, full system, and a random-coalition control.

The first M6 design contains 600 cold tasks across math/proof, code, science, engineering, research, planning, tool use, memory retrieval, error detection, invention, dialogue and orchestration. It must be frozen before dataset building and scanned for overlap.

Measure accuracy, severe-error rate, calibration, transfer, robustness, latency, memory, cost and tool success. Candidate champion threshold: at least 3 absolute accuracy points or 10% relative error reduction, confidence-interval lower bound above zero, no critical-domain regression above 2 points, and independent reproduction.
