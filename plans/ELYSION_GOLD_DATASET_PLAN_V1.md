# ELYSION-GOLD-V1 dataset plan

Status: PROPOSED / DATASET NOT BUILT

Target 8,000–12,000 audited examples covering math/proof, code, science, engineering, research, planning, tool use, memory retrieval, error detection, invention, reasoning, dialogue, orchestration, farm selection and multi-agent coordination.

Each record must carry source ID, source license, content SHA-256, lineage, domain, difficulty, producer model/revision where applicable, verifier, audit status and split. Near-duplicate and semantic-overlap checks run before splitting. M6 is generated/frozen independently and never enters training or teacher context.

Only VALIDATED AGORA material may be proposed for M4 GOLD; validation still does not imply automatic dataset admission.
